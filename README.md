# vlm-pca-exercise
An implementation of principle component analysis on popular VLMs including [QWEN3](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct#processing-long-texts), [LLaVA](https://huggingface.co/liuhaotian/llava-v1.5-7b), and [MolMo](https://huggingface.co/allenai/Molmo-7B-D-0924). We demonstrate the formation of meaningful object count-based structures in later intermediate layers through reasoning when the VLM is extracting the count of an object.
